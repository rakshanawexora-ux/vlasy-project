# VLASY logo

`vlasy-transparent.png` is a transparent web asset prepared from the logo supplied
in chat through a background-removal edit. It contains the full hair emblem,
VLASY lettering, registered symbol and UNISEX SALON line. It is displayed with
its aspect ratio preserved on a cream backing so the black artwork stays visible
on both dark and light sections. Neither CSS filters nor theme recolouring apply.

The same source is configured for both variants in `lib/constants.ts`.
If an original production PNG/SVG becomes available, replace this asset or update
those paths directly. Keep an accessible text alternative and intrinsic dimensions.

Decorative hair-strand SVG artwork is authored separately in
`components/brand/HairFlow.tsx`; it is not used as a replacement logo.
