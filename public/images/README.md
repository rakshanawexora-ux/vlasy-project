# VLASY editorial image collection

The November 2026 campaign contains 52 newly generated individual images in
`editorial/2026-11/`: 50 salon, service, detail, training and interior references,
plus a matched two-image hair-replacement illustration. All photos used by the
site now come from this campaign. The original logo remains unchanged.

The creative direction is consistent: fictional South Indian models, natural
window light, realistic skin and hair texture, ivory walls, brushed brass and
quiet salon scenes. Images are AI-created editorial illustrations, not actual
VLASY clients, staff, branches, classes or documented outcomes. Keep the visible
AI labels and the comparison disclosure. Related sub-services may share a
relevant reference image; there are 85 catalogue entries, not 85 unique photos.

## Resolution and delivery

Each WebP has a 3840-pixel long edge (3840 × 2560). The generator returned
1536 × 1024 source images. The published files are Lanczos-upscaled 4K-size
exports, **not native 4K captures**; resizing does not create native detail.
WebP quality is 86. Next.js serves responsive smaller versions to phones and
uses lazy loading below the fold, rather than downloading every full-size file.

`docs/editorial-assets.json` records each source filename, SHA-256 checksum,
native dimensions, export dimensions, byte size, scene and upscaling status.
Original PNGs remain in `/workspace/generated_images` on this development
instance; that temporary directory is not a durable source archive. The
versioned public path prevents previous image variants from being reused by
image caches after deployment. Archive generated originals separately before
this environment is retired if you need to re-export them later.

## Comparison and motion

The before image depicts approximately 70% top-of-scalp thinning on a fictional
Indian man. The after image was generated by editing the same source to add a
possible hair-system appearance, preserving the face, pose, clothing and light.
They are illustrative concepts, not a clinical result or guarantee.

The short silent hero motion loop is rebuilt from the new campaign hero image.
It retains pause/play, offscreen handling, reduced-motion and data-saver fallbacks.
