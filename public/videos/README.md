# Optional hero motion

`studio-hero.mp4` is a silent H.264 loop made from the native studio hero image,
not recorded salon footage. It uses the image's native 1536 × 1024 framing.
A sharp still photo is the default. Only clicking Play on desktop loads the loop.
Playback pauses offscreen or when hidden; reduced motion, phones, data saver and
media failure keep the still image. The visible AI disclosure applies to both.
